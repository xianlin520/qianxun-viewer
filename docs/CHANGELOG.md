# 变更日志

本文件记录千寻图片查看器（QianXun Viewer）的重要变更。
格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/)，版本号遵循语义化版本。

## [1.4.1] - 2026-10-14

### 修复

- **新 Bucket 兼容（重要）**：阿里云 OSS 自 2025-09-01 起新建的 Bucket 不支持 V1 签名，程序此前固定用 V1 签名，导致新桶下几乎所有在线操作失败（列举/信息/删除均报 AccessDenied）。现按 Endpoint 自动推导地域并使用 V4（`oss2.AuthV4` + `Bucket(region=…)`）；旧桶 V1/V4 均可用，已用真实旧桶回归 13/13 通过。自定义域名/加速域名推导不出地域时退回 V1。依赖下限同步提到 `oss2>=2.18.4`（V4 支持下限）。
- **换桶不再误判**：本地上传索引按 Bucket 分文件存储（`oss_index_<bucket>.json`），更换 Bucket 后不会沿用旧桶的「已上传」记录，避免上传被误跳过、分享指向旧桶对象；切桶同时清空云端 key 缓存。
- 文档补充 RAM 最小权限清单与典型缺权限报错（docs/ONLINE_DESIGN.md §5、docs/USER_GUIDE.md §10）。
- **报错可读化**：「测试连接」与在线库/云端删除/公共读失败改为显示压缩后的错误码+消息，并附可操作提示（V4 签名要求 / 权限不足 / 地域不匹配 / AK 错误 / 阻止公共访问等），「测试连接」成功时标注当前使用的签名版本（V4/V1）。
- **永久直链降级提示**：新建 Bucket 默认开启「阻止公共访问」，对象 ACL 无法设为公共读（`Put public object acl is not allowed`）；程序识别后弹窗说明原因并询问是否改用限时签名外链，同时给出关闭该开关的路径（Bucket「权限管理」+ OSS 全局）。
- **新桶实测（2026-10-14）**：xianlin-oss（cn-qingdao，V4）在补齐 RAM 权限后——测试连接、整桶列举、上传、签名外链匿名 200、缩略图参数签名 200、删除、探测对象自清理全部通过。
- **文档**：新增 [docs/OSS_DEV_MANUAL.md](OSS_DEV_MANUAL.md)——凭据与配置落点、客户端构造/V4 签名、对象命名、接口清单、上行/下行链路、分享链接（临时/长期）、**链接失效机制**（到期/撤回公共读/删改对象/轮换 AK 及各自影响面）、RAM 权限、实测速率与调优、报错对照、代码索引、验证清单。

## [1.4.0] - 2026-09-03（正式版）

v1.3.0 测试期全部增量合并定版，首个含 OSS 在线库的正式发布：

- **在线库增强**：分享双模式（限时签名 ≤7 天 / 单对象公共读永久直链，可撤回）；分享三级解析（remote_key→本地索引→云端清单匹配补登），未上传弹窗确认后单张上传出链；在线查重（pHash 补算、单张排除、整组排除、跨组一键批处理、云端删除带总量确认）。
- **UX**：工具栏 17→8 控件（低频项收进「更多 ▾」+ ● 徽标）；长宽比改选项模式；文件夹下拉常显；查重面板排除勾选。
- **安全**：OSS Secret 改 Windows DPAPI 加密存储，历史明文自动迁移。
- **性能**：闪屏先于单实例检查；打包精简（onefile 52MB / onedir 120MB）。
- 1.3.0 及以前的本地浏览/垃圾桶/查重/缓存等能力不变，见下述各节。

- 2026-09-03：工具栏精简——17 个控件减至 8 个：仅留 打开目录/排序/重新随机/缩略图滑块/搜索/分页模式/在线库/更多；低频项（刷新/查重/仅看最爱/长宽比/垃圾桶/上传/缓存/设置/关于）收进「更多 ▾」菜单；「文件夹」下拉仅有子文件夹时显示；菜单内有生效状态时「更多 ●」徽标提示；重拍 6 张受影响截图。

- 2026-09-03：启动二轮优化——闪屏提前到单实例检查之前（Logo 上屏再做事）；打包精简（QianXunViewer.spec）：剔除未用的 Qml/Quick/Pdf/OpenGL/AVIF 模块与 opengl32sw 软件渲染库，onefile 75→52MB、onedir 166→120MB，单文件版启动解压耗时显著下降；两版精简包冒烟启动通过。

## [1.2.1] - 2026-09-01

### 修复

- 图片墙末行不再拉伸铺满：仅剩少量图片时按目标行高、自然宽度左对齐，杜绝单张图被拉成巨型模糊块；非末行仍保持行内无缝。

## [1.2.0] - 2026-09-01

### 新增

- 长宽比筛选：工具栏可编辑下拉，预设 1:1/4:3/3:2/16:9/2:1/3:4/2:3/9:16/1:2，亦可自定义（如 `1.5:3` 或单个浮点）；对数距离容差 ±10%（整体符合即可），与搜索/最爱叠加生效；损坏图（无分辨率）在筛选时排除。

## [1.1.4] - 2026-09-01

### 优化

- 重复检测分组算法改为「簇代表」聚类：成员必须与组首代表图相似才入组，根治 Union-Find 传递性导致的几十张漂移大组问题。
- 汉明距离默认阈值 6 → 4（更严格），并在「设置」中开放调节（0–12，越小越严格）。

## [1.1.3] - 2026-09-01

### 修复

- 修复关闭窗口后进程残留后台：网络盘 IO 任务未在退出前取消，`QThreadPool` 析构阻塞解释器退出；现关闭时设置取消标志（Scan/Thumb/Decode 均检查）并等待线程池收尾，实测网络扫描中途关窗 5s 内进程完全退出。
- 单实例连接改为正确 `nextPendingConnection()` 接受并读取，避免挂起连接泄漏。

## [1.1.2] - 2026-09-01

### 修复

- 重复组面板预览不显示：原实现硬编码 256 档且使用图片目录缓存路径，与 v1.1.1 本地缓存/512 档不兼容；现改为任意档位缓存回退 + 同步生成兑底。
- 重复组面板布局重整：固定尺寸预览格、组标题、组间分隔线、双向滚动，空预览不再撞坏布局。

## [1.1.1] - 2026-09-01

### 变更

- 缩略图缓存迁移到本地用户目录 `%LOCALAPPDATA%/QianXunViewer/cache/<目录指纹>/`，**不再写入图片目录**——云同步/网盘目录不再因缓存产生上传下载流量；图片目录仅保留 `favorites.json` 与 `Remove/` 小体积数据。旧版遗留在图片目录的 `.qx_cache` 可手动删除。

### 修复

- 修复图片墙视口上滚轮无响应：滚轮事件改由 viewport 事件过滤器拦截（QAbstractScrollArea 子类 wheelEvent 收不到视口事件）。

## [1.1.0] - 2026-09-01

### 新增

- 文件名搜索框：工具栏实时过滤，与排序/最爱叠加。
- 大图旋转 90°（⟳ 按钮 / `R` 键）；右键菜单「复制文件」（可粘贴到资源管理器）。
- 单实例保护：重复启动时激活已有窗口而非开新窗。
- 目录变更自动刷新（800ms 防抖）+ 手动刷新（`F5` / 「刷新」按钮）。
- 缓存管理对话框：占用统计、清理孤儿缓存、清空全部缓存。
- 图片墙键盘导航：方向键移动焦点（蓝色焦点框）、Enter 进大图。

### 优化

- pHash 改为 numpy 自实现（32×32 二维 DCT），移除 imagehash/scipy/PyWavelets，包体显著缩小。
- 缩略图预热改为泵式限量并发（≤8），可见高优先任务始终插队，快速滚动不做无效解码。
- 网络盘/慢速介质健壮性：文件头读取、原图解码、缩略图保存均退避重试，瞬时 IO 错误不再误判「已损坏」。

## [1.0.1] - 2026-08-31

### 优化

- 图片墙滚轮加速：每格滚轮至少滚动一行高度，浏览更跟手。
- 大图浏览器初始比例不再超过 100%（修复以 512 档缓存图计算适应比例导致原图被放大的问题）；原图解码后未手动缩放时自动按原图重新适应。
- 大图浏览器新增可见操作按钮：上一张 ‹ / 下一张 › / 退出 ✕（右上角，保留 Esc/←/→ 快捷键）。

## [1.0.0] - 2026-08-31

首个正式版本。版权所有 © 羡林i (Y_XianLin)。

### 新增

- 图片加载：递归扫描（跳过 `Remove/` 与隐藏目录）、增量呈现、标题统计（张数/总大小）、损坏文件容错计数。
- 图片墙（滚动模式）：justified 无缝拼接、cover 裁切、不显示文件名、行高滑块实时调整。
- 分页模式：页码条、每页数量随窗体自适应、卡片下方基础功能按钮（★/存/拷/位/移）。
- 缩略图：256/512 两档落盘缓存（`sha1(路径|大小|mtime)` 命名、幂等失效）、视口优先调度、EXIF 方向校正。
- 大图浏览器：全屏覆盖层、滚轮缩放 1%~800% 锚定鼠标、拖拽平移、双击适应/100%、←/→ 预加载切换、Esc 返回、F 收藏、512 档先行 + 原图后台无缝替换、超大图降采样。
- 最爱：`favorites.json` 跟随目录（相对路径）、星标角标、仅看最爱、快捷键 F。
- 排序：随机（固定种子）/时间±/大小±，重新随机按钮，信息行随排序变化。
- 图片操作：另存为、复制剪贴板、打开所在位置、移出到 `Remove/`（可逆、重名加后缀）。
- 垃圾桶页面：列出已移出图片、还原回原子目录（`R` 键/右键/卡片按钮）、`.qx_removed.json` 原路径映射。
- 重复检测：pHash（32×32 灰度 64bit）、汉明距离 ≤6 分组、蓝标、重复组面板一键保留最大/最新。
- 设置：默认读取/保存目录；启动自动加载默认目录。
- 体验：拖拽文件夹加载、空态引导、暗色 QSS 主题、高 DPI、F11 全屏、2:1 比例提示、窗口/视图状态记忆。
- 工程：venv 虚拟环境、`build.bat`（onefile）/`build-onedir.bat`、GitHub 标准文档（README/LICENSE/docs）。

### 修复

- 修复切换目录时旧扫描结果混入新库的并发缺陷（加载世代令牌）。
- 修复 worker 信号对象生命周期问题（引用保活 + 退出静默 + 关闭等待线程池）。
- 修复 PySide6 `QPoint + QPointF` 不支持导致的大图绘制异常。
