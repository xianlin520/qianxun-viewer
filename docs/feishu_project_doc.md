# 千寻影集 QianXun Album

> 千张级图片库，滚动不卡，删图能还原。

Windows 桌面图片查看器 · 版本 v1.7.2 · 免安装

![图片](E:\QoderWork\qianxun-viewer\docs\screenshots\feishu_1_doxcnw.png)

图片墙：千张图无缝拼接，末行不拉伸

---

## 它解决什么问题

普通看图软件在几千张图的大目录里，有三个绕不过的毛病：

- **滚动卡顿**：每滚一屏就回去解码原图
- **切目录慢**：要等整个目录扫描完才有画面
- **云盘被拖累**：缓存默认写进图片目录，触发云盘在后台反复上传

千寻影集的做法：

- **网格只读缩略图**：256 和 512 两档落本地磁盘，原图只在打开大图时解码
- **缓存不碰图片目录**：全部放 `%LOCALAPPDATA%`，云盘同步零流量
- **重活全在后台**：扫描、缩略图、解码、移动都走工作线程，界面线程只负责画

## 看图

图片墙是默认视图。不同长宽比的图拼成整行，中间没有空洞。最后一行保持自然大小，不会为了填满把某张图撑成整屏。

![图片](E:\QoderWork\qianxun-viewer\docs\screenshots\feishu_2_doxcna.png)

大图浏览器：512 缓存先显示，原图后台无缝替换

点开进入大图浏览器：

- 滚轮缩放 1%~800%，锚定鼠标位置
- 拖拽平移，双击在适应窗口与原始大小间切换
- 左右键切图，相邻两张已预加载
- 超过 1.2 亿像素的图自动降采样，不吃光内存

分页模式适合逐张翻。每张卡片带信息行和五个按钮：收藏、另存为、复制、定位、移出。

## 找图

![图片](E:\QoderWork\qianxun-viewer\docs\screenshots\feishu_3_doxcn8.png)

重复检测：改过尺寸、换过格式的图也能认出来

文件名搜索、长宽比筛选、文件夹子树筛选，三个条件可以任意叠加。

查重用感知哈希（pHash），比的是画面本身而不是文件名或文件大小。同一张图改过尺寸、重新压过、换过格式，照样能认出来。找到之后一键保留最大或最新的一张，其余移到垃圾桶。

阈值可调。默认 4 偏严格，调到 12 更宽松。误判的能手动勾掉排除，不影响同组其他图。

---

## 移出不是删除

文件被移到目录下的 `Remove/` 文件夹，原始路径记在旁边一个小文件里。垃圾桶页能看到全部移出的图，随时还原回原位置。

从打开程序到关掉它，它不会删除任何一个文件。

## 数据不出本机

默认就是本地模式：程序不联网。

- 打开、浏览、搜索、筛选、查重、移出与还原，全部在本机完成
- 对象存储上传、短链、收藏同步、检查更新，这四类请求在发出前被拦下
- 被拦下的尝试只写本机日志 `%LOCALAPPDATA%\QianXunViewer\egress.log`，只记主机名，不记路径与文件名
- 状态栏右下角常驻角标，写明当前是「本地模式 · 不联网」还是「已联网」

需要联网时到「设置 → 隐私」关掉本地模式。这一步会二次确认，确认框里写清楚之后会传什么。

### 联网之后传什么

- **上传到云**：图片文件本身进你自己的 OSS。对象名是路径哈希（`qx/h/<24位十六进制>.<扩展名>`），云端控制台看不到目录名与文件名
- **生成短链**：服务端记录哈希后的对象名、空备注与时间戳。备注默认留空，不再把文件名当备注传上去
- **同步收藏**：只上传收藏项路径的 24 位哈希，拉取时用本地扫描结果反查。服务端拿不到目录结构
- **检查更新**：只查 Gitee Releases，不上报任何本地信息

扫描完图库不会自动同步收藏。所有出网都由按钮触发，没有静默推送。

## 云端

![图片](E:\QoderWork\qianxun-viewer\docs\screenshots\feishu_4_doxcno.png)

在线库：整桶列举，缩略图走 OSS 图片处理

接入阿里云 OSS 之后（需先在「设置 → 隐私」关掉本地模式）：

- **上传**：增量上传，已传过的自动跳过，不会重传
- **浏览**：直接看云端图库，缩略图走 OSS 图片处理，流量省约 99%
- **分享**：限时签名外链有有效期；分享短链可随时撤销，撤销后立刻打不开
- **统计**：分享记录里能看到每个链接被访问几次、最后一次是什么时候
- **同步**：收藏跨机器同步，本地文件始终为准，云端失败不影响本地

## 功能清单

**浏览**

- 图片墙（justified 布局）、分页模式、大图浏览器
- F11 全屏，方向键导航，回车进大图
- 支持高分屏，深色与浅色两套主题，切换立即生效

**整理**

- 五种排序：随机（固定种子，顺序可重现）、时间升/降、大小升/降
- 文件多选：Ctrl/Shift 选择，右键预选，批量操作
- 重复检测：pHash 感知哈希，一键清理
- 移出与还原，全程无损

**效率**

- 文件夹拖进窗口即加载
- 记住上次的目录、窗口位置、滚动位置
- 目录内文件变化自动刷新
- 启动闪屏，秒开

**云端**

- OSS 增量上传与在线浏览
- 限时外链与可撤销短链
- 收藏同步（游标翻页，不受条数上限影响）

**隐私**

- 本地模式默认开启，四类出网请求在发出前被拦下
- 出网审计日志，只记主机名
- 云端对象名与收藏键均为路径哈希

## 下载

Windows 10/11 x64，不需要装 Python。

- **单文件版** `QianXunViewer-v1.7.2.exe`：一个文件，拷到哪都能跑，首次启动稍慢
- **目录版** `QianXunViewer-v1.7.2-win64.zip`：解压即用，启动更快

下载地址：[Gitee Releases](https://gitee.com/qianxun-cloud/qianxun-viewer/releases)

启动后在本地模式下不联网，也不会检查新版本。关掉本地模式后才会延迟几秒查一次，有新版本才提示，不挡启动；也可以在「更多」菜单里手动检查。
