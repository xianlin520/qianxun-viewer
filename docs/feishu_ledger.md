## 三、云端数据现状

D1 库 `qx-album`，2026-11-16 核对：

- `shares` 43 条（历史短链，未清理）
- `favorites` 2 条（路径哈希之前的原样键，新版本按哈希推送后会自然分层）

三条数据边界：

- 对象存储里只有用户主动上传的图片，对象名是路径哈希
- 服务端只有哈希与时间戳，没有文件名、没有目录名
- 本机的出网日志与设置都在 `%LOCALAPPDATA%\QianXunViewer\`，不上传

## 四、每次发版的检查清单

1. 升版本号：`src/meta.py`、README、ARCHITECTURE 三处一致，跑 `scripts/check_version.py` 确认
2. 跑测试：客户端 `unittest discover -s tests`，服务端 `node --test server/tests/boundary.test.js`
3. 跑冒烟：`qx_smoke_166.py` 十项全过
4. 跑隐私自查：本地模式下把所有出网路径触发一遍，确认 `urlopen` 零调用、`egress.log` 只有主机名
5. 打包：onefile 与 onedir 两个产物，记录字节数
6. 启动验证：离屏启动存活十几秒并正常响应 terminate
7. 提交推送打 tag，建 Release 并上传两个产物
8. 更新本台账与 CHANGELOG
